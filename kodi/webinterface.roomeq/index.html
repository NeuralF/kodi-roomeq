Measure

  1. Plug the measurement mic into the interface input set below (condenser mic: turn on +48 V).
  2. Put the mic at ear height where you listen. Volume: comfortably loud, the sweep plays at −10 dBFS for 8 s.
  3. Record 3-5 points about 30-50 cm apart around the listening spot. More points = broader, safer filters.
  4. Check the curves, then Apply.
